個人利用なら月 $0、多めに使っても月 $1 未満

SelfHostArtifacts を Cloudflare の Workers・D1・R2 で動かしたときの月額の見積もり。お金がかかるのは R2 の保存量だけ。

個人で使う場合
$0 / 月
どの項目も無料枠の 0.5% 未満
多めに使う場合（1年後）
$0.93 / 月
R2 の保存 72GB のうち、無料枠を超えた 62GB 分
有料プラン（月 $5）が要るのは
1.6万 回/日
の閲覧を超えたとき

保存量の伸びと料金

減らすにはKEEP_VERSIONS を設定すると、古い版を毎日の Cron が消すので保存量の伸びが止まる。

無料枠に対する使用量

項目無料枠個人多め

D1 書き込み10万行 / 日約 250 行 / 日約 2,500 行 / 日
R2 保存10GB月 +180MB月 +6GB 超過
R2 書き込み系（Class A）100万回 / 月約 1,200 回約 2万 回

R2 転送量無料——

個人: 公開 20回/日・閲覧 50回/日。多め: 閲覧者 10人、公開 200回/日・閲覧 1,000回/日。
